# Cyber-Security-logo

## Description
This project is a 3D Cyber Security logo created using Onshape. The design represents cybersecurity through a shield, a lock, and circuit-inspired patterns.

## Files
- **cyber Security.gif** – Animated preview of the 3D logo.
- **cyberSecurity.stl** – 3D printable STL model.
- **cyberSecurity logo.zip** – Project files.

## Software Used
- Onshape

## Features
- 3D circular badge
- Shield design
- Lock icon
- Circuit-inspired details
- STL export for 3D printing
